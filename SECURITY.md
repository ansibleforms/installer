# Security Policy

This repository is the installer of AnsibleForms, so most security problems belong to the application.
Please follow the [AnsibleForms security policy](https://github.com/ansibleforms/ansibleforms/security/policy)
and report privately through its
**[Report a vulnerability](https://github.com/ansibleforms/ansibleforms/security/advisories/new)** page.

**Please do not open a public issue for a security problem.**

If the problem is in the installer itself, for example a secret written with loose permissions or a download
not checked, use **[Report a vulnerability](https://github.com/ansibleforms/installer/security/advisories/new)**
on this repository instead.
